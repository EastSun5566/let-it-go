# Benchmark results

Reviewed benchmark JSON files belong here. Include the commit SHA, machine, OS, browser version, viewport, device scale factor, repetition count, warm-up, and sample duration in the accompanying PR summary.

Production decisions require all three pinned Ubuntu attempt artifacts and the aggregate gate output. macOS runs remain non-blocking cross-platform observations and must be reported without selecting favorable reruns.

Do not commit raw Chromium trace files, Playwright reports, screenshots, or short harness-check output as decision evidence.
